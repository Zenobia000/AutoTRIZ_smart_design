## 3. UI 互動模式

### 3.1 AI 生成 → 人確認 模式

所有 AI 生成的內容都遵循同一互動模式：

```
[🤖 AI 生成] 按鈕
    ↓
Loading spinner + "AI 正在生成..."
    ↓
顯示 AI 生成結果 (可展開/收合)
    ↓
用戶可以：
  - [✏️ 編輯] → 進入編輯模式，修改內容
  - [✅ 確認] → 儲存並進入下一步
  - [🔄 重新生成] → 再呼叫一次 AI
```

### 3.2 表格編輯模式

假設台帳、方案集合、風險登錄表等使用 Streamlit `st.data_editor`：
- 可直接在表格中編輯
- 支援新增/刪除行
- 修改後自動儲存

### 3.3 進度指示

Sidebar 的每個步驟旁邊顯示狀態：
- ○ 未開始
- ◉ 進行中
- ✅ 已完成
- ⚠️ Gate 未通過

## 4. 技術實作要點

| 元件 | Streamlit 實作 |
|------|---------------|
| 導航 | `st.sidebar` + `st.radio` |
| 表格 | `st.dataframe` (唯讀) / `st.data_editor` (可編輯) |
| 表單 | `st.form` + `st.text_input` / `st.text_area` |
| 下拉 | `st.selectbox` |
| 展開 | `st.expander` |
| 進度 | `st.progress` / `st.status` |
| Loading | `st.spinner` |
| 警告 | `st.warning` / `st.error` / `st.success` |
| 匯出 | `st.download_button` |
| 狀態管理 | `st.session_state` |

## 5. 頁面流程圖

```
首頁 (建立專案)
  │
  ├── Phase I
  │   ├── 任務定義表 (AI生成 → 人確認)
  │   ├── 索克拉底問答 (AI提問 → 人回答)
  │   ├── 矛盾識別 (AI識別 → 人確認)
  │   └── Gate 1 ✓
  │
  ├── Phase II
  │   ├── 假設台帳 (AI提取 + 人補充)
  │   ├── TRIZ 解法 (AI生成 → 人評估)
  │   ├── SCAMPER 變形 (AI生成 → 人篩選)
  │   ├── 方案集合 (AI彙整 + 人編輯)
  │   ├── MUST 快篩 (人評估)
  │   └── Gate 2 ✓
  │
  ├── Phase III
  │   ├── WANT 條件設定 (人設定權重)
  │   ├── WANT 評分 (人評分 + AI計算)
  │   ├── 風險評估 (AI識別 + 人判斷)
  │   ├── KT 決策記錄 (AI草稿 → 人簽核)
  │   ├── 最小實驗 (AI建議 + 人確認)
  │   └── Gate 3 ✓
  │
  └── 匯出報告
```
