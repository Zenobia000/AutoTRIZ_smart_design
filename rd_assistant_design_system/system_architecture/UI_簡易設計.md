# UI 設計 - RD Design Copilot

> **版本**: v2.0 | **日期**: 2026-02-25
> **設計哲學**: Apple-style Progressive Disclosure + AI as Invisible Infrastructure

---

## 0. 設計原則

### Apple 哲學三支柱

| 原則 | 定義 | 在本系統的實踐 |
|------|------|---------------|
| **Progressive Disclosure** | 只在需要時才顯示複雜度 | Gate 內嵌於流程，不另開頁面；AI 結果預設收合 |
| **Direct Manipulation** | 用戶操作即產出 | 填表 = 建立工件；拖拉 = 排序方案；點擊 = 展開細節 |
| **AI as Invisible Infrastructure** | AI 是基礎設施，不是主角 | 用戶看到的是「結果」，不是「AI 正在思考」 |

### 必填 vs Agent 處理

| 分類 | 說明 | 視覺表現 |
|------|------|---------|
| **必填** (Human Input) | 用戶必須提供的核心判斷 | 白底輸入框 + 紅色星號 |
| **Agent 處理** (Auto) | AI 自動生成，用戶可修改 | 灰底卡片 + "AI" 標籤 + 編輯按鈕 |
| **必須呈現** (Display) | 系統計算結果，不可編輯 | 彩色徽章 / 進度條 / 圖表 |

## 4. UI 互動模式

### 4.1 AI 生成 → 人確認 模式

```
[觸發條件] → AI 自動/按鈕觸發
    ↓
結果以灰底卡片顯示 + [AI] 標籤
    ↓
用戶可以：
  - [採用] → 直接使用
  - [編輯] → 修改後儲存
  - [重生成] → 再呼叫一次
  - [跳過] → 不使用此結果
```

### 4.2 Gate 內嵌模式

Gate 不是獨立頁面，而是每個功能頁底部的 checklist：

```
── Gate X.X ──────────────────────────────
✅ 條件1 已滿足
⚠️ 條件2 部分滿足 (點擊查看詳情)
❌ 條件3 未滿足

[通過 → 下一步]  或  [返回補強]
──────────────────────────────────────────
```

Phase Gate 則加上醒目的里程碑標記：

```
═══ Phase Gate N ═══════════════════════
✅ 所有條件通過
[進入 Phase N+1: XXXX]
════════════════════════════════════════
```

### 4.3 進度指示 (Sidebar)

```
Phase 1: Define
  ● Brief      ← 綠點=完成
  ● Explore    ← 綠點=完成
Phase 2: Diverge
  ◉ Track      ← 藍環=進行中
  ○ Create     ← 空圈=未開始
Phase 3: Converge
  ○ Review
  ○ Decide
```
