# TRIZ 物理矛盾分離原則

> **用途**：Step 2.2.3，當矛盾為物理矛盾（同一物件需同時具備矛盾屬性）時，使用分離原則找解法方向。
> **注入方式**：全量注入 Prompt 上下文（~1,000 token）。

## 什麼是物理矛盾？

物理矛盾 = 同一個系統參數需要同時滿足兩個相反的要求。

```
範例：轉子需要同時「高轉速」和「低振動」
       ──── 矛盾屬性A ────   ── 矛盾屬性B ──
```

## 四大分離原則

### 1. 時間分離 (Separation in Time)

**核心問題**：屬性 A 和屬性 B 是否需要在**不同時間**出現？

| 策略 | 說明 | 工程範例 |
|------|------|---------|
| 預先動作 | 在需要之前先完成 | 預熱、預載、預緊 |
| 事後動作 | 在不需要時切換狀態 | 冷卻後回彈、自恢復材料 |
| 週期性動作 | 交替切換兩種狀態 | 脈衝散熱、間歇潤滑 |
| 加速/減速 | 改變時間尺度避開矛盾 | 快速通過共振區、慢速精密定位 |

**適用判斷**：若「高轉速」只在加速時需要，「低振動」只在巡航時需要 → 時間分離。

### 2. 空間分離 (Separation in Space)

**核心問題**：屬性 A 和屬性 B 是否可以在**不同位置**實現？

| 策略 | 說明 | 工程範例 |
|------|------|---------|
| 局部品質 | 不同區域不同屬性 | 表面硬、芯部韌（表面處理） |
| 分割/組合 | 把系統拆成不同區域 | 雙層結構（內剛外柔） |
| 嵌套 | 物件套物件 | 同心管、多層密封 |
| 幾何變換 | 改變幾何配置 | 偏心設計、非對稱佈局 |

**適用判斷**：若「剛性」在承力區需要，「柔性」在減振區需要 → 空間分離。

### 3. 條件分離 (Separation upon Condition)

**核心問題**：屬性 A 和屬性 B 是否在**不同條件**下需要？

| 策略 | 說明 | 工程範例 |
|------|------|---------|
| 相變/狀態變化 | 利用物理狀態改變 | 形狀記憶合金（溫度觸發） |
| 參數變化 | 某參數超過閾值時切換 | 過載保護、限扭器 |
| 環境響應 | 隨環境自動調整 | 溫控風扇、自適應阻尼 |
| 場效應 | 施加外場改變屬性 | 磁流變液、電致變色 |

**適用判斷**：若「高扭矩」在低速爬坡時需要，「低噪音」在高速巡航時需要 → 條件分離。

### 4. 整體與局部分離 (Separation between Whole and Parts)

**核心問題**：整體需要屬性 A，但局部可以用屬性 B 組合出 A 的效果？

| 策略 | 說明 | 工程範例 |
|------|------|---------|
| 複合結構 | 用不同材料/結構組合 | 碳纖+鋁合金混合結構 |
| 多孔/中空 | 整體輕但局部強 | 蜂巢結構、中空軸 |
| 梯度/漸變 | 屬性漸變而非二元 | 梯度材料、漸變齒形 |
| 自相似/碎形 | 不同尺度重複結構 | 分形散熱鰭片 |

**適用判斷**：若「整體要輕」但「局部要強」→ 整體與局部分離。

## 分離原則選擇流程

```
物理矛盾: [物件] 需要同時 [屬性A] 和 [非屬性A]
                    │
        ┌───────────┼───────────┬──────────────┐
        ▼           ▼           ▼              ▼
   A和B在不同    A和B在不同   A和B在不同    整體要A
   時間出現？    位置需要？   條件下需要？  局部可以B？
        │           │           │              │
        ▼           ▼           ▼              ▼
   時間分離      空間分離     條件分離     整體局部分離
```

> **注意**：一個物理矛盾可能同時適用多個分離原則，應產出多條候選策略供後續篩選。
